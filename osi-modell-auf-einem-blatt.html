Alle 7 Schichten auf einen Blick

Kapselung

Wie Daten durch die Schichten wandern

PDU je Schicht

Jede Schicht hat ihre eigene Bezeichnung für die Dateneinheit (PDU - Protocol Data Unit): Schicht 4 Segment, Schicht 3 Paket, Schicht 2 Frame, Schicht 1 Bits. Schicht 5-7 arbeiten meist einfach mit "Daten".

OSI vs. TCP/IP

Gegenüberstellung

Geräte-Vergleich

Router, Switch, Firewall

Router

Layer 3 verbindet unterschiedliche Netzwerke, leitet Pakete anhand der Ziel-IP-Adresse weiter.

Switch

Layer 2 verbindet Geräte innerhalb desselben Netzwerks, leitet Frames anhand der MAC-Adresse weiter.

Firewall

Layer 3/4 (klassischer Paketfilter) prüft und filtert Datenverkehr nach IP-Adresse und Port. Eine Application-Firewall/WAF arbeitet zusätzlich auf Layer 7.

Merksatz: Switch verbindet im Netz, Router verbindet Netze, Firewall kontrolliert, was durchdarf.

Grundlagen

Was ist das OSI-Modell

OSI-Referenzmodell

Schichtenmodell mit 7 Ebenen zur Beschreibung der Netzwerkkommunikation. Jede Schicht übernimmt eine klar abgegrenzte Aufgabe und nutzt die Dienste der darunterliegenden Schicht.

Merksatz: Je höher die Schicht, desto näher am Anwender. Je tiefer, desto näher an der Hardware.

Zwei Gruppen

Schicht 5-7: anwendungsorientiert (Daten, Formate, Sitzungen)

Schicht 1-4: transportorientiert (Übertragung, Adressierung, Wegfindung)

Die 7 Schichten

Layer 7 bis 1
Anwendungsorientiert

7Anwendung / Application

TCP/IP-Schicht: Anwendung / Application

Schnittstelle zum Nutzer. Stellt Funktionen für Anwendungen bereit, ermöglicht die Verbindung zu den unteren Schichten. Hier findet die Dateneingabe und -ausgabe statt.

Protokolle: HTTP, FTP, SMTP, DNS

Adressen: URLs, Hostnamen

Geräte: Proxy, Gateway

6Darstellung / Presentation

TCP/IP-Schicht: Anwendung / Application

Datenformatierung. Bereitet die Daten so auf, dass sie dem Nutzer angezeigt werden können. Zwei Anwendungen verwenden dabei üblicherweise die gleiche Kodierung.

Protokolle: TLS, SSL, JPEG, ASCII

5Sitzung / Session

TCP/IP-Schicht: Anwendung / Application

Sitzungssteuerung. Ermöglicht Verbindungen zwischen Endsystemen. Die Zeit zwischen Öffnen und Schließen der Kommunikation wird als Sitzung bezeichnet.

Protokolle: NetBIOS, RPC

Transportorientiert

4Transport

TCP/IP-Schicht: Transport

Adressierung von Anwendungen und Prozessen. End-to-End-Kommunikation zwischen zwei Geräten, Bindeglied zwischen transportorientierten und anwendungsorientierten Schichten. Zur Übertragung wird das Gesamtpaket in kleinere Bestandteile zerlegt.

Protokolle: TCP, UDP

Adressen: Ports

Geräte: Firewall

3Vermittlung / Network

TCP/IP-Schicht: Internet

Routing. Reguliert den Datentransfer zwischen zwei verschiedenen Netzwerken - innerhalb eines Netzwerks fällt diese Schicht weg. Segmente aus Layer 4 werden in Fragmente aufgeteilt und beim Empfänger wieder zusammengefügt.

Protokolle: IP, ICMP

Adressen: IP-Adressen

Geräte: Router

2Sicherung / Data Link

TCP/IP-Schicht: Netzzugang / Network Access

Lokale Adressierung. Ermöglicht eine zuverlässige Verbindung zwischen Endgerät und Übertragungsmedium innerhalb desselben Netzes. Pakete aus Layer 3 werden in kleinere Teile zerlegt, sogenannte Frames.

Protokolle: Ethernet, ARP

Adressen: MAC-Adressen

Geräte: Switch

1Bitübertragung / Physical

TCP/IP-Schicht: Netzzugang / Network Access

Physische Übertragung. Elektrische, mechanische und funktionale Schnittstelle zum Übertragungsmedium - beinhaltet die Datenübertragung der beteiligten physischen Geräte wie Kabel und Hub.

Geräte: Hub, Kabel

Eselsbrücke

Reihenfolge merken

Alle Prüfer Suchen Tests Nach Der Pause

Erster Buchstabe je Wort = erster Buchstabe der englischen Schichtnamen, von oben (7) nach unten (1):

A - Application (7) P - Presentation (6) S - Session (5) T - Transport (4) N - Network (3) D - Data Link (2) P - Physical (1)

Mit den deutschen Namen (Anwendung, Darstellung, Sitzung, Transport, Vermittlung, Sicherung, Bitübertragung) ergeben sich andere Anfangsbuchstaben, der Merksatz passt nur zu den englischen.

Merksatz: A-P-S-T-N-D-P - jeder Prüfer sucht Tests nach der Pause.

Einordnung im Netzwerk

802.3 (Ethernet) und 802.11 (WLAN) liefern die physische/logische Anbindung der Endgeräte an Switch bzw. Access Point - Layer 1/2. VLAN (802.1Q) teilt ein physisches Netz logisch auf, ebenfalls Layer 2. Router und Firewall sitzen dahinter auf Layer 3/4.

Wenn's hakt

Hilfe bei Bearbeitungsstillstand

Zuordnung eines Geräts/Protokolls unklar

Fragen, auf welcher Adressart das Gerät arbeitet: MAC = Layer 2, IP = Layer 3, Port = Layer 4.

Firewall wirkt mehrdeutig

Klassische Paketfilter-Firewall arbeitet auf Layer 3/4 (IP + Port). Application-Firewall/WAF auf Layer 7. Für eine einfache 1-Gerät-pro-Layer-Zuordnung: Router = Layer 3, Firewall = Layer 4.

OSI und TCP/IP verwechselt

OSI hat 7 Schichten, TCP/IP nur 4. Schicht 5-7 des OSI-Modells entsprechen zusammen der Schicht Anwendung / Application im TCP/IP-Modell.

Reihenfolge der Schichten vergessen

Von oben (7) nach unten (1): Anwendung / Application, Darstellung / Presentation, Sitzung / Session, Transport, Vermittlung / Network, Sicherung / Data Link, Bitübertragung / Physical.
